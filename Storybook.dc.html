구조가 보이는
컴포넌트 시스템.

MODUL은 토큰 → 컴포넌트 → 모션 → 템플릿으로 쌓이는 하나의 라이브러리입니다. 컴포넌트는 headless: 필수 props만 정의하고 나머지 네이티브 속성은 ...rest로 루트 엘리먼트에 그대로 전달합니다. 같은 부품으로 포트폴리오, 홈페이지, 어드민을 확장합니다.

원칙
  1. 모든 값은 토큰에서 온다. hex, px, 폰트명을 직접 쓰지 않는다.
  2. Headless 계약: 컴포넌트는 필수 props + ...rest. 네이티브 속성(aria-*, data-*, type, form, onX…)을 막지 않는다.
  3. 정렬과 룰이 구조를 만든다. 장식, 그림자 남용, 둥근 모서리 없음.
  4. 모션은 짧고 물리적으로. 위치·스케일·불투명도만 움직인다.
  5. 동작은 Radix, 모양은 토큰. 포커스 트랩·roving tabindex·포지셔닝이 필요한 컴포넌트(Checkbox · Radio · Tabs · Accordion · Popover · Menu · Tooltip · Dialog)는 Radix 위에 className 만 얹는다. Radix 에 없는 것(Select 검색 · Combobox · Pagination · Toast · Table)만 직접 만든다.

Headless 계약 — 컴포넌트 작성 규칙
import { forwardRef, type ComponentPropsWithoutRef } from 'react';
import { cx } from './cx';

// 1. 필수/고유 props 만 정의 — 나머지는 네이티브 타입에서 상속
type ButtonOwnProps = {
  variant?: 'primary' | 'secondary' | 'ghost';
  size?: 'sm' | 'md' | 'lg';
  icon?: React.ReactNode;
};
export type ButtonProps = ButtonOwnProps & ComponentPropsWithoutRef<'button'>;

// 2. forwardRef + ...rest 를 루트에 전달 — className / style 은 병합
export const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  ({ variant = 'primary', size = 'md', icon, className, children, ...rest }, ref) => (
    <button
      ref={ref}
      type="button"                              // 기본값, rest 의 type 이 덮어씀
      className={cx('btn', `btn-${variant}`, `btn-${size}`, className)}
      {...rest}
    >
      {children}{icon}
    </button>
  ),
);

// 3. 다형성이 필요하면 as / asChild
<Button as="a" href="/work">작업 보기</Button>

다형성 — as / asChild

스타일은 컴포넌트가, 엘리먼트는 사용자가 정합니다. 두 가지 방식을 모두 제공하되 기본은 as, 라우터 링크처럼 자식이 이미 엘리먼트인 경우는 asChild.

as — 태그 교체
타입이 as 값에 따라 바뀜. as="a" 면 href 가 허용되고 disabled 는 거부됨.
작업 보기 (a)
asChild — 자식에 병합
자식 엘리먼트 하나에 className·props·ref 를 병합. <Link>, <motion.a> 같은 외부 컴포넌트에 사용.

Polymorphic 타입 유틸
import type { ComponentPropsWithoutRef, ComponentPropsWithRef, ElementType } from 'react';

type AsProp<C extends ElementType> = { as?: C };
type PropsToOmit<C extends ElementType, P> = keyof (AsProp<C> & P);

export type PolymorphicProps<C extends ElementType, Own = {}> =
  Own & AsProp<C> & Omit<ComponentPropsWithoutRef<C>, PropsToOmit<C, Own>>;

export type PolymorphicRef<C extends ElementType> = ComponentPropsWithRef<C>['ref'];

// 사용 — 기본 태그를 두 번째 제네릭으로
export type ButtonProps<C extends ElementType = 'button'> =
  PolymorphicProps<C, { variant?: Variant; size?: Size; icon?: React.ReactNode }>;
Slot — asChild 구현
import { Children, cloneElement, isValidElement, forwardRef } from 'react';

export const Slot = forwardRef<HTMLElement, { children: React.ReactNode } & Record<string, unknown>>(
  ({ children, ...slotProps }, ref) => {
    const child = Children.only(children);
    if (!isValidElement(child)) return null;
    return cloneElement(child, {
      ...slotProps,
      ...child.props,                                        // 자식 props 우선
      className: cx(slotProps.className, child.props.className),
      style: { ...slotProps.style, ...child.props.style },
      ref: mergeRefs(ref, (child as any).ref),
    });
  },
);

// Button 내부
const Comp = asChild ? Slot : (as ?? 'button');
return <Comp ref={ref} className={cx('btn', `btn-${variant}`, className)} {...rest} />;

공통 규칙
  • 오버레이(Modal · Drawer · Sheet · ⌘K)는 열릴 때 첫 포커스 가능 요소로, 닫힐 때 열었던 트리거로 포커스 복귀. Esc 는 항상 닫기.
  • 복합 위젯(Tabs · Menu · Listbox · Radio)은 Tab 정지 하나 + 화살표로 내부 이동 (roving tabindex).
  • 비활성 컨트롤은 Tab 에서 빠지되 이유를 aria-describedby 로 붙인다 (bottling 규칙).
  • 토스트는 포커스를 훔치지 않는다 — role=status, 액션은 Tab 으로 도달 가능.
